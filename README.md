# Welcome to RD's Webring

## How to Join

 1. Add `<div id="webring"></div>` to your homepage.
 2. Add `<script src="https://webring.rdhosted.com/script.js"></script>` somewhere below it.
 3. Add your site link to [links](https://github.com/robsd/webring/blob/main/links.json) and submit a PR.
 4. Once approved, the widget will be visible on your homepage and member sites will link to yours!

## Rules

- Your site must be online most of the time.
- Your homepage's code must contain the widget (steps 1 and 2).
- Questionable sites will not be accepted.
